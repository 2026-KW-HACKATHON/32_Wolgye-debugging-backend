## 구현 내용
- `GET /garages`: 같은 골목의 다른 빌라, 공개 공유 조건이 걸린 활성 칸 하나씩. `availability`(AVAILABLE/SOON_EXIT/RESERVABLE/UNAVAILABLE), `filter`, `q`(이름·주소), `lat`/`lng` 거리순, 커서 페이지네이션
- `GET /garages/{garage_id}`: 칸별 `offer`·`state`(AVAILABLE/SOON_EXIT/IN_USE)·`estimated_free_at`/`in_use_until`, `summary`
- `POST /share-requests`: 201, 가격 고정, 400/404/409(`GARAGE_TIME_CONFLICT`, `INSUFFICIENT_TOKENS`), 관리인 `SHARE_REQUEST` 알림, 차감 없음
- `GET /share-requests/{id}`: 본인 요청만 (아니면 404), `APPROVED` ↔ DB `ACCEPTED`
- `GET /me/share-requests`: 내 요청 최신순 페이지
- `services/share_requests.accepted_share_at(db, slot_id, at)` / `accepted_shares_at`: 현서 #8·#9 용

## 명세와 다르게/명세에 없어서 정한 것
- 상세 범위: 같은 골목의 다른 빌라만, 아니면 404 (목록과 같은 범위)
- 요청 범위: 비공개·비활성 칸·다른 골목은 404, 내 빌라 칸은 400 (`db-design-issues.md` 2-1)
- 이미 끝난 시간(`request_date + end_hour` ≤ 지금)은 400. 진행 중인 시간대는 허용
- 남의 차량 `vehicle_id` 는 404
- 요일·기간 밖은 400 "이용할 수 없는 날짜입니다." + `detail.weekdays`
- 칸에 공유 조건이 여럿이면 가장 먼저 이용할 수 있는 것 하나
- `summary`: 공유 칸이 없으면 모두 null, `max_hours` 는 하나라도 제한 없음이면 null
- `/me/share-requests` 는 결정 14·25 대로 페이지네이션 (`next_cursor` 포함)
- 출차 시간이 지났는데 아직 주차 중인 차는 `SOON_EXIT` (PR #22 규칙을 따른 결과)
