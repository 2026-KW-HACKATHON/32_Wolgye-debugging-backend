# #24 칸 이름을 빌라 안 순번 P1, P2 …로 적용

- 이슈: #24 (새로 만듦) · 브랜치: `feat/24-slot-label` · Epic #16
- 작업: 관리자(Claude, 메인 세션)가 직접 함

## 배경
- PR #23(FE 합의, 2026-10-03 머지)으로 명세 열린 질문 2가 확정됐다. 칸 이름(`label`, `slot_label`)은 **빌라 안 순번 `P1`, `P2` …** (Figma `주차 배치도 SVG` node 125:2 표기)
- 코드에는 구 규칙(`구역 이름 + 번호`, 예: "필로티 안쪽 1번")이 세 곳에 따로 있었다
  - `services/admin.py` `slot_label()` (main, #14)
  - `services/share_requests.py` `slot_label()` (#12 WIP)
  - `services/admin_shares.py` `slot_label()` (#13 WIP)
  - PR #22(#7, 미머지)는 `services.admin.slot_label`을 import 한다

## 구현
- 새 공통 함수 `app/services/slot_labels.py`
  - `building_slot_labels(db, building_id)`: 빌라의 모든 칸 `{slot_id: "P순번"}` (순번 순서)
  - `slot_labels(db, slot_ids)`: 여러 빌라에 걸친 칸도 한 번에
  - `slot_label(db, slot_id)`: 칸 하나, 없으면 404 `NOT_FOUND`
  - 순번: `row_number() OVER (PARTITION BY building ORDER BY garages.sort_order, garages.id, parking_slots.number)`
- `services/admin.py`: 구 `slot_label()` 삭제, 대시보드(대기 요청·실시간)·칸 목록·칸 설정 응답을 공통 함수로 교체
- 공통 함수 커밋 `c626768`을 먼저 만들고 #12·#13 작업(서브 에이전트)이 그 위로 rebase 해서 같은 함수를 쓰게 했다

## 정한 것 (명세에 없음)
- 같은 `sort_order`면 주차 구역 id 순 (순서가 매번 같도록)
- 비활성 칸도 순번에 넣는다. 명세 예시에서 비활성 칸 1005가 `P5`이고, 칸을 껐다 켤 때 이름이 바뀌면 안 되기 때문
